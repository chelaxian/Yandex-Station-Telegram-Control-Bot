# 3.0.0b2 — установщики и Telegram-интерфейс

Комплекты Windows/Linux включают код бота и закреплённые бинарники LUNA для Мини 3 Про и Станции 2 на проверенных семействах retail .50. Зависимости хоста загружаются при установке. Бот работает на ПК/сервере; на колонках устанавливается LUNA. Нужен уже включённый root ADB; получение root и прошивка не выполняются.

Windows: распаковать installer.zip и запустить install.cmd. Linux Debian/Ubuntu: распаковать installer.tar.gz и выполнить bash install.sh. README содержит требования, размещение данных, режимы проверки и особенности автозапуска. Windows запускает задачу после входа пользователя; Linux использует systemd. ПК должен оставаться включённым.

98 тестов, lint и сборка проходят. Проверки покрывают отказ до записи для неизвестной модели/прошивки, контрольные суммы, конфликты ADB-портов, отсутствие широкого завершения процессов и пути службы. Это не доказательство полной установки на чистой ОС. До аппаратной проверки нового managed install path релиз остаётся draft-кандидатом; действующий бот мини-ПК использует предыдущий проверенный deployment.

В README добавлен скриншот; docs/TELEGRAM_RELEASE_POST.md — готовый текст поста (не отправлен в канал). Возможности интерфейса и аппаратные проверки прежней версии описаны в docs/VALIDATION.md. Поддержка остальных моделей, штатного музыкального провайдера и автономного Python-бота внутри колонки не заявляется.
