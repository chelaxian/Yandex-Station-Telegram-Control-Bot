# Станция Макс: экспериментальная интеграция

Станция Макс YNDX-0008 и Станция 2 используют пересекающееся имя платформы Android. Установщик не должен считать совпадение этого имени подтверждением модели: существующий профиль Станции 2 для Макса не подходит. Поддержка автоматической установки на Макс пока не включена.

В отдельном [черновом PR LUNA](https://github.com/nyakokitsu/luna/pull/33) исследуется backend кольца. По предоставленным владельцем данным кольцо — framebuffer 24×1, 24 bpp, а матрица — 25×16, 24 bpp. Порядок цветов, доступ к устройству и взаимодействие со штатной подсветкой ещё предстоит подтвердить на реальной колонке. Экран, звук, громкость и микрофон на Максе не квалифицированы.

Клиент бота использует `expected_model` и возможности `/api/device`. После проверки экспериментального LUNA можно отдельно проверить подключение бота через защищённый локальный туннель с `expected_model = "yandexstation_max"`. Доступность пункта меню не доказывает работу оборудования; результаты следует записывать отдельно по каждой функции и версии.

Запуск другого экземпляра LUNA может остановить существующий из-за общего lock. Перед экспериментом владелец должен проверить наличие работающей LUNA и сохранить её настройки; не запускать тест параллельно с ней. Никаких операций с прошивкой, OTA или сбросом для этой проверки не требуется.
