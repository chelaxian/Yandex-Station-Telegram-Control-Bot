🚀 **Yandex Station Telegram Control Bot 3.0.1**

Управляйте Яндекс Станциями из Telegram: оформленные карточки, кнопки действий и несколько колонок в одном боте.

🔉 Громкость, подсветка и экран
🎙 Запись комнаты, голосовые и TTS
🎛 Саундборд, звуковые темы и сирена
📞 Интерком с обменом аудиофрагментами
⏰ Таймеры и будильники
💻 Терминал, свои скрипты и бэкапы
📸 Камера хоста и охрана при настроенном источнике
👥 Доступ друзьям по @username с подтверждением владельца

🖥 Бот работает на Windows/Linux, LUNA — на колонках. ПК или сервер должен оставаться включённым. Для установки на колонку нужен уже настроенный root ADB.

🧩 Что нового:
• Официальная LUNA v0.2.23: поддержаны наши правки для Station 2, Mini 3 Pro и audio/owner API
• Управляемые обновления LUNA с проверкой контракта и автоматическим откатом
• Исправлен служебный ADB shell для реальной Station 2
• Rollback-копия LUNA стала hard-link — установка занимает меньше места
• Саундборд Лайт 2 учитывает громкость станции и блокируется при 0%

🧪 Квалифицированы Станция 2 и Мини 3 Pro на retail .50; Лайт 2 Plum — экспериментально. Остальные модели, persistence после перезагрузки и штатный музыкальный плеер ещё требуют проверки.
