🚀 **Yandex Station Telegram Control Bot 3.1.0**

Управляйте Яндекс Станциями из Telegram: громкость, подсветка, запись, звуки, интерком и другие функции доступны через кнопки.

✨ Подсветка теперь доступна и для моделей, у которых LUNA предоставляет только световую зону logo.
⏱ В ответе на запись показывается фактическая длительность полученного аудио.
🧪 Проверили основные вызовы на 12 виртуальных профилях КУЯСЭ и опубликовали результаты с ограничениями.
🛠 Добавили сценарий для повторной проверки в изолированном эмуляторе.

Бот работает на Windows или Linux, LUNA — на колонке. Для установки нужны работающий root ADB и включённый ПК или сервер.

Квалификация реальных устройств и автоматической установки по-прежнему ограничена Станцией 2, Мини 3 Про и экспериментальной Лайт 2 Plum. Эмуляция не заменяет проверку звука, микрофонов и других функций на реальных колонках.
