# 3.0.0b1 — восстановление прикладных функций 2.7

Переход с alpha возвращает голосовые сообщения, MP3/WAV-саундборд, русский TTS, автоматические звуковые темы, сирену/эффект бана, интерком, экранные пресеты/яркость, будильники, камеру хоста/охрану, ZIP-бэкапы, хранение образов, терминал и скрипты. Сохранены поддержка нескольких станций, роли и доступ по username с подтверждением владельцем.

Для звука нужны ffmpeg/espeak-ng на хосте и LUNA audio.jobs.v1. Результат воспроизведения и очистка проверяются отдельно от принятия запроса. Исправлено зависание ALSA после отмены воспроизведения. Терминал требует явно включённых owner tools; автоматические темы — owner.speech.phase.v1.

Минимальный квалифицированный fork runtime: [LUNA 0f2393e](https://github.com/chelaxian/luna/commit/0f2393e4d613472c79755b358abc3047a9466963). Это расширение fork, а не обещание наличия этих API в любом upstream релизе.

Проверки: 65 тестов бота, 75 Rust-тестов LUNA, сборка wheel/sdist и credential guard. На мини-ПК сохранены прежние конфигурация, история, session и 15 звуков. На Станции 2 и Мини 3 Про проверены audio jobs, отмена и последующее воспроизведение, TTS, Telegram upload/download, owner scripts/system и запись WAV. Входящие updates тестов синтетические; слышимость пользователем не подтверждена.

Ограничения перед стабильным релизом:

- Автономная установка на колонку не завершена: подготовленный комплект не помещается в свободную постоянную память двух проверенных устройств. Он не устанавливался; boot/persistence нового бота не проверены.
- Штатная музыка Алисы требует отдельного авторизованного провайдера; /media пока работает с зарегистрированными провайдерами LUNA. TTS «Алиса, следующий трек» не выдаётся за надёжное управление.
- Как и в исходном 2.7, интерком обменивается аудиофрагментами; это не Telegram calls. /ask — локальный помощник, а не облачная Алиса; образы сохраняются с SHA-256, разделы не прошиваются.
- Физическая камера не настроена; pipeline проверен на синтетическом видео. Голосовой приём/отбой и автоматические темы по реальной речи требуют проверки с пользователем.
- Остальные модели и длительная работа не квалифицированы. LUNA на двух устройствах пока запускается из /tmp и не переживает reboot автоматически.
