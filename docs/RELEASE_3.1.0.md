# 3.1.0 — подготовка

Бот показывает управление подсветкой станций, у которых LUNA предоставляет только зону logo. Для такой зоны пресеты цвета и возврат штатной подсветки отправляются на поддерживаемые LUNA endpoints; эффекты кольца не предлагаются. На станциях с кольцом и логотипом управление обеими зонами сохранено.

В подписи WAV указывается фактическая длительность записи; если она меньше 80% запрошенной, бот показывает предупреждение. Интерком останавливается с объяснением, если получает слишком короткий фрагмент. Виртуальный микрофон при запросе 1 секунды вернул около 0,38 секунды; физические устройства по этому результату не оцениваются.

Проведены предварительные тесты HTTP-адаптера в КУЯСЭ для 12 профилей. Добавлены сценарий проверки и [матрица результатов](KUYASE_VALIDATION.md), включая расхождение виртуального LED-триггера Лайт 2. Эмуляция не подтверждает реальный звук, микрофон или корректную работу установщика на новой модели.

Автоустановка LUNA по-прежнему ограничена Station 2, Mini 3 Pro и экспериментальной Lite 2 Plum. Поддержка штатного музыкального плеера, некоторые модели и полная проверка всех функций остаются незавершёнными. Этот файл — подготовка релизных заметок, а не подтверждение публикации или выполнения всех критериев выпуска.
