# Release 3.0.1

**3.0.1** переводит проект с временного LUNA-форка на официальный [LUNA v0.2.23](https://github.com/nyakokitsu/luna/releases/tag/v0.2.23) (commit `b6ddd7f4e70f985256d01343899697a076f6ce05`). Upstream принял PR #24 с аппаратной поддержкой Station 2 / Mini 3 Pro и PR #28 с audio jobs, owner tools и speech phase.

## Изменения

- Provision использует официальные бинарники и закрепленные SHA-256 для Mini 3 Pro, Station 2 и Лайт 2 Plum.
- Автообновление LUNA включено под управлением Supervisor. После рестарта проверяются модель и обязательные capabilities; потеря контракта откатывается на квалифицированную копию, а опасный цикл обновлений приостанавливается.
- Qualified rollback и инсталляционный previous-бинарник создаются hard-link, поэтому managed-установке достаточно около 8 МиБ постоянной памяти вместо дополнительных полных копий.
- Исправлен служебный протокол ADB shell: убраны backslash-маркеры, которые реальная Station 2 раскрывала иначе, и поддержан вывод `cat` без финального перевода строки.
- `deploy/adb_luna_forward.py` явно поддерживает remote port; managed LUNA слушает `127.0.0.1:18100`.
- Саундборд Лайт 2 учитывает громкость станции и отказывает в воспроизведении при 0% (аппаратно подтверждено внешним тестером).

## Проверка

- 140 unit-тестов, Ruff, Python build и installer build — PASS.
- Финальный installer TAR проверен в Linux CT126: `install.sh --check` подтвердил SHA-256 bundle и зависимости хоста.
- Рабочая Linux-служба мини-ПК обновлена до 3.0.1: Supervisor active/running, два туннеля, один poller, обе станции отвечают на контракт LUNA.
- Реальные Station 2 и Mini 3 Pro работают на официальном LUNA v0.2.23 и сообщают `audio.jobs.v1`, `owner.tools.v1`, `owner.speech.phase.v1`.

## Границы

Физическая перезагрузка колонок и persistence LUNA не проверялись в этом выпуске. Штатный музыкальный провайдер, остальные модели колонок и чистая первая установка на посторонней машине остаются вне квалификации 3.0.1. Python работает только на хосте; на колонках используется статический Rust-бинарник LUNA.
