## 🌟 Основные возможности и поддерживаемые модели

### 📻 Поддерживаемые колонки (автоопределение при подключении):
* **Яндекс Станция Мини 3 и Мини 3 Про (`bergamot` / `plum`):** ARM64, кольцо 24 RGB AW21018, 7-сегментный LED-экран, 8 микрофонов.
* **Яндекс Станция Мини 2 (`chive` / `yandexmini_2`):** Версии с LED-часами и без часов, верхняя подсветка, 4 микрофона, раздел `/data/opt`.
* **Яндекс Станция Мини 1 (`yandexmini` / `micro`):** Верхний датчик жестов, 4 микрофона, ALSA Playback/Master, раздел `/data/opt`.
* **Яндекс Станция Лайт 2 (`lemon`):** LED-матрица глаз/эмоций, компактная акустика, раздел `/data/opt`.
* **Яндекс Станция Лайт 1 (`onion` / `yandexlite`):** Базовая модель, верхний светодиод, ALSA Line Out, раздел `/data/opt`.
* **Яндекс Станция Миди (`cucumber`):** ARM64, LED-часы, RGB-кольцо, нейропроцессор.
* **Яндекс Станция 2 (`station2`):** ARM64, верхняя световая сенсорная панель.
* **Яндекс Станция Макс (`yandexmax`):** LED-матричный монохромный экран, мощная акустика.

### 🤖 Функционал Telegram Control Bot:
* Полноценное интерактивное меню с кнопками.
* Автономный и фоновый режим службы (Windows Service / Linux Daemon).

## ⚡ Оптимизация памяти (RAM & CPU)

В версии v2.5 полностью решена проблема высокого потребления оперативной памяти и нагрузки на процессор:
1. **Режим ожидания камеры (Zero-RAM Standby):** Камера не захватывает кадры в холостом режиме. Захват активируется **только** при открытии веб-сайта трансляции, включении видеоохраны или ручной записи. При закрытии вкладки или отключении охраны камера мгновенно освобождается (`cap.release()`), память очищается сборщиком мусора (`gc.collect()`), снижая нагрузку на ПК до 0%.
2. **Отключение пулов OpenCL:** В OpenCV принудительно отключены фоновые структуры OpenCL (`cv2.ocl.setUseOpenCL(False)`), что устранило раздувание виртуальной памяти (VSZ) на 2.5–3 ГБ.
3. **Ограничение потоков:** Число внутренних потоков OpenCV жестко ограничено (`cv2.setNumThreads(1)`).
4. **Компактный кольцевой буфер движения:** Снижен размер буфера предзаписи до оптимальных 30 кадров и активен строго во время детекции.

## 📁 Структура файлов и папок

В корне архива находятся **только скрипты установки и запуска**, а все внутренние файлы, код и библиотеки вынесены в отдельную папку `bot/`:

```text
Telegram_Control_Bot/
├── setup.bat               # ⚙️ Мастер установки для Windows (в 1 клик)
├── setup.sh                # ⚙️ Мастер установки для Linux (в терминале)
├── setup.py                # ⚙️ Кроссплатформенный запуск установщика через Python
├── start.bat               # ▶️ Быстрый запуск бота на Windows
├── start.sh                # ▶️ Быстрый запуск бота на Linux
├── start.py                # ▶️ Запуск бота через Python
├── START.vbs               # 🚀 Запуск без проблем с ассоциациями .bat файлов (Windows)
├── ИНСТРУКЦИЯ.md           # 📖 Эта подробная инструкция
└── bot/                    # 📦 Вся внутренняя начинка бота (в отдельной папке!)
    ├── bot.py              # Основной движок бота
    ├── setup.py            # Внутренний мастер настройки и заливки файлов
    ├── run_bot.py          # Монитор автоперезапуска бота
    ├── manage_bot.sh / .py # Управление фоновым сервисом
    ├── config.ini          # Настройки (токен, IP колонки, админ)
    ├── allowed_users.json  # Список пользователей с доступом (@username / ID)
    ├── requirements.txt    # Зависимости Python
    ├── sounds/             # Аудиофайлы саундборда
    ├── speaker_scripts/    # Скрипты для Яндекс Станции (RGB, LED, микрофон)
    └── tools_adb/          # Встроенный ADB для Windows и Linux
```

## 💻 Инструкция для Windows (10 / 11)

### Шаг 1. Подготовка окружения
1. Скачайте и установите **Python 3.10, 3.11 или новее** с официального сайта [python.org](https://www.python.org/).
2. ⚠️ **ВАЖНО:** Во время установки обязательно отметьте галочку **«Add python.exe to PATH»** внизу окна!

### Шаг 2. Автоматическая установка (в 1 клик)
1. Запустите файл **`setup.bat`** (или `setup.py` / `START.vbs`) двойным кликом мыши.
2. В мастере установки выберите режим:
   * `[1]` — **Установить бота НА СТАНЦИЮ** (автономная работа 24/7, ПК можно выключить).
   * `[2]` — **Запустить бота НА КОМПЬЮТЕРЕ** (работает, пока включен ПК).
3. Мастер автоматически:
   * Быстро отсканирует Wi-Fi сеть и найдет IP-адрес вашей Яндекс Станции.
   * Попросит указать токен бота из [@BotFather](https://t.me/BotFather) и ваш Telegram `@username` или ID.
   * Загрузит необходимые скрипты и звуки на колонку.

### Шаг 3. Запуск бота
* Запустите **`start.bat`** (или `START.vbs` / `python start.py`).
* Откройте Telegram и напишите боту `/start`.

## 🐧 Инструкция для Linux (Ubuntu, Debian, Fedora, Arch и др.)

### Шаг 1. Установка системных утилит
Откройте терминал и выполните:
```bash
# Для Ubuntu / Debian / Linux Mint:
sudo apt update
sudo apt install -y python3 python3-pip python3-venv ffmpeg

# Для Fedora / RHEL:
sudo dnf install -y python3 python3-pip ffmpeg

# Для Arch Linux / Manjaro:
sudo pacman -S python python-pip ffmpeg
```

### Шаг 2. Запуск мастера установки
1. Перейдите в папку с распакованным архивом:
   ```bash
   cd Telegram_Control_Bot
   chmod +x setup.sh start.sh setup.py start.py
   ```
2. Запустите мастер:
   ```bash
   ./setup.sh
   # или: python3 setup.py
   ```
3. Выберите режим установки (на Станцию или на ПК), подтвердите найденный IP колонки и укажите токен с вашим `@username`.

### Шаг 3. Запуск бота
```bash
./start.sh
# или: python3 start.py
# или управление сервисом: ./bot/manage_bot.sh start
```

## 💬 Настоящая история диалогов с Алисой

* Нажмите кнопку **`[ 💬 История диалогов ]`** или отправьте команду `/history`.
* **Тихий режим (без спама):** По умолчанию бот аккуратно сохраняет все новые запросы в базу диалогов, не засоряя чат уведомлениями на каждое слово домочадцев.
* Выберите нужную дату (например, `📅 29.10.26 (Сегодня)`).
* Бот выведет точные фразы:
  * `[10:35:12] 🗣️ Вы: «Алиса, включи рок»`
  * `└ 🟣 Алиса: «Включаю: легенды рока на Яндекс Музыке»`
* Кнопка **`[ 🔔 Уведомления в чат ]`** позволяет включить мгновенные push-сообщения, если вам нужно следить за разговорами в реальном времени.

  * *«Сделай потише»*
  * *«Брось монетку»*

  1. Алиса **отвечает своим настоящим голосом** (высококачественный нейросетевой синтез речи с естественными интонациями и поддержкой Yandex SpeechKit)!

  3. Алиса сама воспроизводит ответ через динамик колонки в комнате.
  4. Текст ответа **моментально приходит в Telegram**.
  5. Разговор аккуратно заносится в историю диалогов без лишнего спама.

## 🛡️ Охранная система компьютера (Anti-Theft Guard)

* Меню `[ 🛡️ Охрана ПК ]` или команда `/guard on`.
* **Доступные режимы охраны:**
  * 💻 **Только ПК:** реагирует на любое движение мыши или клавиши клавиатуры.
  * 👂 **Только Звук:** микрофоны Станции слушают комнату и реагируют на шум/голоса.
  * 📹 **Камера:** оптический видеодатчик движения через веб-камеру.
  * 🛡️ **Полная охрана:** комбинация всех датчиков одновременно.
* **При тревоге:**
  * Станция врубает громкую полицейскую сирену и красно-синий стробоскоп.
  * Экран ПК автоматически блокируется.
  * В Telegram моментально присылается снимок нарушителя с камеры и 3-секундная видеозапись происшествия!

## 📞 Звонки в Telegram (VoIP Интерком со Станцией)

Функция **«📞 Звонки в Telegram»** превращает вашу Яндекс Станцию в полноценный переговорный VoIP-интерком с голосовым управлением вызовом прямо возле колонки!

### 🔔 Как работает входящий звонок:
1. Вы нажимаете **`[ 📞 Позвонить на Станцию (Вызов) ]`** в Telegram-боте.
2. Яндекс Станция начинает проигрывать официальный фирменный рингтон входящего вызова, верхнее кольцо мягко пульсирует бирюзовым цветом, а на LED-экране отображается `CALL`.
3. Человек в комнате может ответить или сбросить звонок голосом:
   * **🗣️ Фразы для ПРИНЯТИЯ вызова:**
     * *«Алиса, принять»*, *«Прими»*
     * *«Алиса, ответь»*, *«Ответь»*
     * *«Алиса, возьми трубку»*, *«Возьми»*
     * *«Слушаю»*, *«Алло»*, *«Да»*, *«Давай»*
     * *«Соедини»*, *«На связи»*, *«Говори»*
   * **🔴 Фразы для ОТКЛОНЕНИЯ или ЗАВЕРШЕНИЯ звонка:**
     * *«Алиса, отклони»*, *«Отбой»*, *«Сбрось»*
     * *«Не сейчас»*, *«Завершить»*, *«Положи трубку»*
     * *«Хватит»*, *«Стоп»*, *«Занят»*, *«Нет»*
   * *(Также звонок можно принять или сбросить вручную кнопками в Telegram)*.

### 🎙️ Общение во время звонка (Двусторонняя связь):
* При ответе колонка издает звук соединения, светодиод загорается постоянным зеленым, а экран переключается в `TALK`.
* **Вы говорите в Telegram:** любые голосовые сообщения или текст, отправленные в чат, Станция моментально озвучивает в комнате через динамик.
* **Собеседник говорит возле колонки:** 8 микрофонов Станции в реальном времени слушают комнату и циклично отправляют голосовые фрагменты собеседника прямо в ваш Telegram-чат!
* Для завершения разговора скажите *«Алиса, отбой»* или нажмите кнопку `[ 🔴 Завершить звонок ]`.

## 🔊 Кастомные звуки в Саундборд (.mp3 и .wav)

Теперь вы можете добавлять любые собственные звуки и мемы прямо через Telegram-чат:
1. Откройте **`[ 🔊 Саундборд и Мемы ]`** и нажмите **`[ ➕ Добавить свой звук (.mp3/.wav) ]`**.
2. Отправьте любой аудиофайл в формате **.mp3** или **.wav** (или запишите голосовое сообщение).
3. Бот автоматически:
   * Сконвертирует аудио в формат 48000 Гц 16-бит PCM WAV;
   * Сохранит файл локально и загрузит в память Станции (`/bkupgrade/data/opt/sounds/`);
   * Создаст новую интерактивную кнопку запуска в меню Саундборда.
4. Вы можете нажать кнопку и мгновенно воспроизвести звук на колонке!
5. Чтобы удалить ненужный звук, используйте кнопку **`[ 🗑️ Удалить свой звук ]`**.

## 📦 Прошивка, Дампы и Резервное копирование (Бэкап)

Раздел **`[ 📦 Прошивка и Бэкап ]`** предназначен для полного контроля над системным ПО и настройками Станции:
* **💾 Скачать полный бэкап (.zip):**
  * В 1 клик собирает все пользовательские скрипты, звуковые файлы, конфигурации диалогов и кнопок в единый ZIP-архив и присылает файл прямо в Telegram.
* **📥 Загрузить и восстановить бэкап:**
  * Позволяет отправить сохраненный ZIP-архив в бот для полного автоматического восстановления Станции после сбоя или переустановки.
* **📤 Загрузить дамп / прошивку (.img/.bin):**
  * Позволяет отправить файлы дампов разделов или образы прошивок (`.img`, `.bin`, `.ota`, `.ubi`).
  * Бот автоматически загружает их во внутреннюю память Станции (`/bkupgrade/data/firmware/`), рассчитывает точную контрольную сумму SHA-256 и выводит безопасные команды для прошивки через Терминал (`flash_erase`, `nandwrite`).
* **🔍 Карта разделов MTD / UBI:**
  * Показывает точную разметку Flash-памяти колонки (`mtd0` bootloader, `mtd1` tpl, `mtd2` boot, `mtd3` system, `mtd4` nv, `mtd5` bkupgrade, `mtd6/7` recovery).

В меню **`[ 🩺 Диагностика железа ]`** доступна полная телеметрия аппаратной части в реальном времени:
* **🌡️ Температура процессора (CPU):** точный замер с термодатчика SoC (🟢 < 50°C норма, 🟡 50–68°C тепло, 🔴 > 70°C перегрев).
* **⚡ Частота и режим CPU:** текущая тактовая частота (до 1.20 ГГц) и регулятор частоты (`interactive` / `performance`).
* **📈 Загрузка системы (Load Average):** средняя нагрузка за 1, 5 и 15 минут.
* **🧠 Оперативная память (RAM):** наглядная визуальная шкала `[█████░░░░░] 54% (129 / 238 МБ)` с детализацией занятой и свободной памяти.
* **💾 Встроенный Flash-диск (/bkupgrade):** процент заполнения и остаток свободного места в пользовательском разделе.
* **📶 Параметры Wi-Fi:** имя сети SSID, диапазон частот (2.4 ГГц или 5 ГГц) и точный уровень сигнала **RSSI в dBm** с оценкой качества связи.
* **⏱️ Аптайм системы:** время непрерывной работы Станции без перезагрузок (дни, часы, минуты).

## ❓ Решение частых проблем (FAQ)

### 1. Колонка не подключается по ADB (`offline` или `Connection refused`)
* Проверьте, включен ли режим ADB на Станции:
  Зажмите кнопку отключения микрофонов (или комбинацию активации отладки) в соответствии с вашей прошивкой.
* Проверьте пинг до колонки:
  `ping 192.168.0.100` (подставьте свой IP).
* Попробуйте переподключить ADB вручную:
  * Windows: `tools_adb\adb.exe connect 192.168.0.100:5555`
  * Linux: `./tools_adb/adb connect 192.168.0.100:5555`

### 2. На Linux ошибка доступа к веб-камере (`Permission denied` или `can't open camera`)
Добавьте вашего пользователя в группу `video`:
```bash
sudo usermod -aG video $USER
```
После этого перезагрузите компьютер или перезайдите в систему.

### 3. Ошибка `No module named ...` при запуске
Убедитесь, что библиотеки установлены:
* Windows: `pip install -r requirements.txt`
* Linux: `pip3 install -r requirements.txt` (или в виртуальном окружении `.venv`).

### 4. Не отправляются видео или фото в Telegram
Убедитесь, что на компьютере установлен утилитный пакет **ffmpeg** (в Windows обычно распаковывается в PATH, в Linux ставится через `sudo apt install ffmpeg`).
